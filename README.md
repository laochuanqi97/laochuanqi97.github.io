# Chuanqi Lao — Personal Website

Simple English academic homepage: white background, profile and contacts in a left column, academic content in a right column. Responsive layout with no external runtime dependencies. Open `index.html` to preview locally.

## Edit

Update contact links and publication entries in `content.js`. Edit the biography in `index.html` and the research-interest list in `app.js`. A CV link can be configured later. The current design has no photo or decorative illustration.

The supplied Google Scholar URL is an author search, so the website labels it **Google Scholar Search**. Replace it with a direct profile URL containing `user=...` when available. Personal GitHub: https://github.com/laochuanqi97.

## Publish on GitHub Pages

1. Sign in as `laochuanqi97` and create a public repository named `laochuanqi97.github.io`.
2. Upload `index.html`, `content.js`, `app.js`, `style.css`, `favicon.svg`, and `.nojekyll` to its root.
3. In Settings → Pages, choose Deploy from a branch, `main`, and `/ (root)`.
4. Once deployment completes, visit `https://laochuanqi97.github.io`.

Official guide: https://docs.github.com/en/pages/quickstart

Published on October 10, 2026: https://laochuanqi97.github.io/

Repository: https://github.com/laochuanqi97/laochuanqi97.github.io
